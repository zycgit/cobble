# Cobble Loader

&emsp;&emsp; 资源加载、类加载、处理 Jar in Jar、类隔离工具框架。

## 加载能力

- 支持加载自定义目录中的资源
- 支持加载独立 Jar/Zip 包中的资源
- 支持多个加载器聚合为一个
- 可以加载 Jar in Jar 中的资源

## 资源扫描

- 支持扫描系统类，例如：rt.jar
- 内置 6 种资源匹配策略
    - None：扫描所有资源
    - ContainsAny 含有字符串
    - Match：全字匹配
    - Prefix：前缀匹配
    - Suffix：尾缀匹配
    - Regex：正则表达式匹配
- 支持自定义匹配策略

## 类加载

- 遵循双亲委派机制
- 资源加载器可转化为等价的类加载器
- 资源扫描可转化为等价的类扫描
  - 类扫描仅加载匹配到的类，没有匹配的类不会触发类加载
