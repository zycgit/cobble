# Cobble 工具包

&emsp;&emsp; cobble 译名:鹅卵石，是一种非常常见的小石头。通常用来当作建筑辅材以及景观布置。

分为 6 个部分：

- cobble-lang，一些整理工具类和组建。
- cobble-dynamic，基于 ASM 的 Java 动态代理、及类编辑工具。
- cobble-settings，提供统一的配置文件访问接口，同时兼容 properties、xml、yaml 三种格式。
- cobble-loader，资源的扫描/加载、加载器编排、类隔离/沙箱 工具框架。
- cobble-logging，各路日志封装工具，来自于 Apache MyBatis3。
- cobble-uncouple，提供 SPI、EventBus 解耦机制。
